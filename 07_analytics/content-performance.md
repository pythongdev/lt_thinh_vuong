# Content Performance Log

> Mỗi bài đã đăng **một dòng**. Đo tại 24h / 72h / 7 ngày.
> Chưa có bài nào chạy qua pipeline mới → bảng đang trống. Không điền số ước lượng.

---

## Bảng theo dõi

| Ngày đăng | Giờ | Idea | Pillar | Persona | Obj | Format | Reach | View | %xem hết | Eng | Save | Inbox | Qualified | Đơn | Doanh thu |
|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|---|
| | | | | | | | | | | | | | | | |

> Cột **Giờ** ghi giờ bấm đăng thật (vd `20:15`), không phải giờ dự định.
> Đây là nguồn duy nhất để sau này trả lời được câu "khung giờ nào tốt" —
> bỏ trống một dòng là mất vĩnh viễn một điểm dữ liệu.

## Điểm theo 4 trục

| Idea | Awareness | Trust | Consideration | Conversion | Nhận xét |
|---|---|---|---|---|---|
| | | | | | |

---

## Cách ghi

1. Đăng xong → thêm dòng, điền tới cột Format (**có cả Giờ**), để trống phần số.
2. Sau 24h → điền Reach / View / %xem hết / Eng.
3. Sau 72h → điền Save / Inbox / Qualified.
4. Sau 7 ngày → điền Đơn / Doanh thu, chấm 4 trục theo `metrics.md` mục 4.
5. Nhận xét: **một câu** nói vì sao bài này chạy hoặc không chạy.

## Cấm
- Điền số nhớ áng chừng. Không lấy được số → để trống, ghi `n/a`.
- Chấm bài bằng trục không đúng objective của nó.
- Xoá bài chạy kém. Bài kém là dữ liệu học quan trọng nhất.

## Top / Bottom mỗi tuần
Cuối tuần liệt kê 3 bài tốt nhất + 3 bài kém nhất theo **đúng trục objective của chúng**,
rồi đưa sang `09_workflows/weekly-learning.md`.
