# Format Library

Mỗi format = một khuôn sản xuất. Format quyết định **cách trình bày**, không quyết định nội dung.

| File | Format | Objective mạnh nhất |
|---|---|---|
| `reels.md` | Video ngắn | O1, O2 |
| `post.md` | Bài ảnh đơn | O5 |
| `carousel.md` | Album nhiều ảnh | O2, O4 |
| `story.md` | Story 24h | O3, O5 |
| `comparison.md` | So sánh | O4 |
| `product-review.md` | Review 1 máy | O4, O5 |
| `customer-story.md` | Chuyện khách hàng | O3 |

Cấu trúc chi tiết cho Facebook/TikTok vẫn nằm ở `04_content/templates/`.
File format bổ sung phần **nhịp, độ dài, visual, lỗi thường gặp** cho từng dạng.
