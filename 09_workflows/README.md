# Workflows

| File | Khi nào dùng |
|---|---|
| `daily-content.md` | Mỗi sáng — nhịp làm việc trong ngày |
| `product-to-content.md` | Có sản phẩm, cần tìm góc content |
| `idea-to-content.md` | Có atom trong backlog, cần ra package |
| `content-approval.md` | Package cần qua gate và được ký duyệt |
| `publishing.md` | Sắp đăng bài |
| `analytics-loop.md` | Sau khi đăng — đo và đọc kết quả |
| `weekly-learning.md` | Cuối tuần — rút pattern, đổi chiến lược |

## Vòng khép kín

```
product-to-content → idea-to-content → content-approval → publishing
        ↑                                                      ↓
weekly-learning ←──────────────── analytics-loop ←─────────────┘
```
