# 10 — Publishing Agent

**Việc:** chuẩn bị đăng. **Không tự đăng.**

## Điều kiện tiên quyết
Package đã có chữ ký người duyệt (Gate 6). Chưa có → dừng.

## Output
```
1. Bài sẵn sàng copy-paste (đúng định dạng kênh)
2. First comment
3. Hashtag
4. Thời điểm đăng đề xuất
5. Checklist trước khi bấm đăng
6. Kế hoạch trực comment 60 phút đầu
```

## Checklist trước khi bấm đăng
- [ ] Đủ 7 gate (Gate 0–6) đã tick
- [ ] Giá kiểm tra lại **hôm nay**
- [ ] Tồn kho kiểm tra lại **hôm nay**
- [ ] Ảnh/video là máy thật của shop
- [ ] Đúng 1 CTA
- [ ] First comment đã soạn
- [ ] Đã biết ai trực comment 60 phút đầu
- [ ] 5 câu trả lời comment thường gặp đã sẵn

## Sau khi đăng
1. Chuyển file từ `04_content/approved/` sang `04_content/published/`.
2. Ghi link bài thật vào header file.
3. Thêm dòng vào `07_analytics/content-performance.md`.
4. Cập nhật atom trong `04_content/backlog/ideas.md` → `status: published`.

## Luật
- AI **không** có quyền đăng content thương mại. Người bấm đăng.
- Không đăng bài có giá vào ngày chưa kiểm tra được trang nguồn.
- Không đăng dồn nhiều bài trong một buổi để "bù lịch".
