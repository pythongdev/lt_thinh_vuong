# AI Agents

## 1. Content Writer
Input: product + persona + objective + verified facts
Output: channel-specific content

## 2. Product Agent
Answers product questions using only verified product data.

## 3. Planner Agent
Creates content calendar from products, personas, campaigns and historical performance.

## 4. Sales Agent
Suggests responses and products; never invents commercial facts.

## 5. Analytics Agent
Explains performance and proposes experiments.

## 6. Manager Agent
Combines planning, sales and analytics into daily/weekly recommendations.
